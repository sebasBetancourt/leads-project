# Leads Automatize — BrainSol

  Sistema para automatizar la prospección de clientes en toda Colombia:

  1. **Búsqueda de leads**: negocios que puedan necesitar una aplicación o sistema a medida.
  2. **Contacto automatizado**: mensajes personalizados por correo o WhatsApp.
  3. **Envío de propuestas**: propuestas comerciales con nuestro portafolio de 3 proyectos.

  Sitio: https://brainsol.vercel.app/

  ## Estructura (propuesta)
  - `scraper/`: búsqueda y enriquecimiento de leads
  - `outreach/`: plantillas y envío de mensajes
  - `proposals/`: generación de propuestas
  - `data/`: leads (no se versiona)
